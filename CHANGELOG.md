# Changelog

## 1.0.0 — first release

**English**

Art Downloader downloads whole galleries and comics from DeviantArt (and other sites supported by gallery-dl) into tidy folders, in reading order.

- Windows installer, portable ZIP and a one-file Linux AppImage — everything inside, no Python or terminal needed
- Folders, chapters, series with sub-folders, galleries, profiles and single works; every image of multi-image posts
- Reading order by the numbers in titles, so parts posted out of order still land in place; one folder per gallery folder; optional `Chapter 01, 02 …` split
- 18+ works through the official “Connect DeviantArt” sign-in; the password is never stored
- Parallel downloads, automatic retry, Stop and resume; parts published later are inserted in place
- Export chapters to CBZ (lossless) or PDF
- Desktop notification when a download finishes; daily update check, one-click gallery-dl update
- Light and dark themes; English, Русский, Українська, Español, 日本語, 中文

**Русский**

Art Downloader скачивает целые галереи и комиксы с DeviantArt (и других сайтов, которые поддерживает gallery-dl) в аккуратные папки, по порядку чтения.

- Установщик для Windows, переносной ZIP и AppImage для Linux одним файлом — всё внутри, ни Python, ни терминал не нужны
- Папки, главы, серии с подпапками, галереи, профили и отдельные работы; все картинки постов с несколькими изображениями
- Порядок чтения по числам в названиях — части, выложенные вперемешку, встают на свои места; своя папка для каждой папки галереи; разбивка по `Chapter 01, 02 …` по желанию
- Работы 18+ через официальный вход «Подключить DeviantArt»; пароль не сохраняется
- Скачивание в несколько потоков, автоповтор, «Стоп» и продолжение; части, вышедшие позже, встают на свои места
- Экспорт глав в CBZ (без потерь) или PDF
- Системное уведомление по окончании; ежедневная проверка обновлений, обновление gallery-dl одной кнопкой
- Светлая и тёмная тема; English, Русский, Українська, Español, 日本語, 中文
